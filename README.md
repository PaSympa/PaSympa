### Featured project · [`discord-mcp`](https://github.com/PaSympa/discord-mcp)

[![npm](https://img.shields.io/npm/v/@pasympa/discord-mcp?style=flat-square&logo=npm&label=npm)](https://www.npmjs.com/package/@pasympa/discord-mcp)
[![Docker](https://img.shields.io/docker/v/pasympa/discord-mcp?style=flat-square&logo=docker&label=docker&sort=semver)](https://hub.docker.com/r/pasympa/discord-mcp)
[![Stars](https://img.shields.io/github/stars/PaSympa/discord-mcp?style=flat-square&logo=github&color=yellow)](https://github.com/PaSympa/discord-mcp)
[![License](https://img.shields.io/github/license/PaSympa/discord-mcp?style=flat-square)](https://github.com/PaSympa/discord-mcp/blob/main/LICENSE)

A lightweight, multi-guild **Discord MCP server with 95+ tools** that gives AI assistants full control over Discord — messages, channels, roles, permissions, members, forums, webhooks, scheduled events, invites, DMs, and moderation. TypeScript + discord.js, ~25 kB package, ~73 MB Docker image.

Works with **Claude Desktop**, **Claude Code**, **Cursor**, **VS Code Copilot**, or any MCP-compatible client.
